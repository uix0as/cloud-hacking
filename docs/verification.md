# 검증 기록

검증 환경: Node.js 25, Java 17, macOS. 로컬 개발 서버에서 확인했습니다. 자동 테스트는 프런트엔드 6개, 백엔드 4개를 통과했습니다.

## 자동 검증

- TypeScript 타입 검사와 Vite 프로덕션 빌드
- 상태 엔진: 12개 명령의 전체 진행, 오타와 순서 오류, 비밀번호 마스킹, 보조 명령, 이력 제한
- Spring Boot 통합 테스트: 전체 진행, 세션 유지와 분리, 초기화, 요청 필드 검사, 단계 충돌, 잘못된 콘텐츠 유형

## 브라우저 검증

- 데스크톱 1280px: 인프라 맵과 터미널의 두 열 배치
- 모바일 390px: 단계 카드, 세로 배치, 접힌 메뉴, 가로 스크롤 없음
- 잘못된 첫 명령이 오류를 표시하고 진행률은 0%로 유지
- 1단계 완료 후 클라우드 이전 단계로 전환
- 새로고침 후 5번째 명령부터 진행도 복원
- 명령 채우기와 Enter로 최소 권한 및 추가 인증 조건 적용
- 비인가 세션의 Access Denied와 0 bytes 출력
- 정상 세션의 GetObject 허용과 100% 완료
- 결과 리포트의 이전·이후 비교
- 초기화 확인 후 처음 상태로 복구
- Spring Boot 연결 모드에서도 12개 명령 완료 및 새로고침 후 세션 복원
- 모바일 메뉴와 개념 라이브러리 열기·닫기
- 터미널 패키지 갱신 후 새 콘솔 오류 없음

결과는 실제 인프라의 침해나 방어를 검증한 것이 아닙니다. 제품의 가상 상태 전이와 UI를 검증한 것입니다.
